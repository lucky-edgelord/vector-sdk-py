# BDScript example bot

    pip install vector-sdk-py
    VECTOR_NSEC=nsec1... vector-bdscript run examples/bdscript

Commands: `!ping`, `!balance` (also `/balance`), `!daily`, `!top`, `!poll <question>` (buttons),
`!quiz` (awaited command), `!catfact` (HTTP + JSON), `!whoami` (Vector-only functions), and a welcome message.
Edit any `.bds` file while the bot runs; it reloads automatically.
